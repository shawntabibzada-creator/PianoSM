falling-note piano tutorial → real sheet music

PianoSM

Watches a Synthesia-style tutorial video's falling note colors, tracks exactly when each key is played, and turns that into MusicXML and MIDI sheet music.

View on GitHub Get started

How it works

1

Calibrate

calibrate_keymap.py reads a frame of the video and auto-detects the keyboard's position and all 88 key coordinates, instead of requiring hand-measured pixel positions.

2

Detect

keyboard_detector.py watches each key's falling bar switch from its pastel (falling) color to its saturated "played" color right as it reaches the keys, and logs every press and release with exact timing and hand.

3

Transcribe

json_to_sheet.py infers tempo from the actual spacing between notes, quantizes to the right rhythmic grid, and writes proper two-hand sheet music with ties and 8va/8vb brackets where needed.

Get started

pip install -r requirements.txt

python calibrate_keymap.py --video data/videos/downloaded_video.mp4
python keyboard_detector.py --url "https://youtube.com/watch?v=..." \
    --keymap data/keyboard_map.json
python json_to_sheet.py --input data/tracked_notes.json

Every stage writes a log to data/logs/, and keyboard_detector.py also writes a plain per-note note_events.csv, so a run stays inspectable instead of only reporting a final count. Full details are in the README.

Worth knowing

  • Every pixel threshold is scaled to the video's actual resolution and adapts to that video's own note colors — a keymap built once can be reused across videos downloaded at whatever resolution YouTube happens to serve.
  • Black-key x-positions from calibration are a geometric approximation, not measured — check the debug overlay image before trusting a run.
  • Same-hand notes are printed as a single line per staff; a sustained note under a moving line gets clipped at the next onset rather than drawn as a second voice.
